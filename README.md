# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ完結のWebサイトです。空をイメージした、明るくやわらかいデザインにしています。

> 本サイトのデモ用コンテンツです。会社名・人物・住所・数値はすべてフィクションです。

## サイトの構成

ページ上部のナビゲーションから、各セクションへ移動できます。

| セクション | 内容 |
| --- | --- |
| お知らせ | 最新のニュース・採用情報 |
| ヒーロー | キャッチコピーと会社の紹介 |
| 私たちについて | 会社の理念と実績の数字 |
| 事業内容 | 受託開発、クラウド、AI活用など6つのサービス |
| 導入事例 | 物流・医療・小売のプロジェクト例 |
| 会社概要 | 基本情報と沿革 |
| お問い合わせ | 相談フォーム(デモのため送信されません) |

## 技術構成

- HTML / CSS / JavaScript のみ(ビルド不要、`index.html` 1ファイルで完結)
- フォントに Google Fonts の Zen Maru Gothic を使用(オフラインでは代替フォントで表示されます)

## ブラウザで開く手順

1. このリポジトリを取得します。

   ```sh
   git clone <リポジトリのURL>
   cd company-site
   ```

2. `index.html` をブラウザで開きます。次のいずれかの方法で開けます。

   - **macOS:** ターミナルで `open index.html` を実行
   - **Windows:** エクスプローラーで `index.html` をダブルクリック
   - **共通:** `index.html` をブラウザのウィンドウにドラッグ&ドロップ
